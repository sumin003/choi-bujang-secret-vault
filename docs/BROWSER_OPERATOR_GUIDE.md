# 브라우저 등록 요청과 운영자 승인

이 기능은 자료실 자체의 운영자 승인 방식입니다. 제공 엔진의 API를 호출하거나 연동했다고 주장하지 않습니다. 쿠키는 브라우저의 서버 기록을 찾는 용도이며, 승인은 별도로 기록한 운영자 결정을 서버가 확인합니다. 심판용 판정기는 별개로 유지하며 반 엔진 연동이라고 주장하지 않습니다. 물리적 기기를 증명하는 인증서·패스키 방식이 아닙니다.

## 설정

기존 등록 테이블이 없는 새 DB에서는 `BROWSER_REGISTRATION_SETUP.sql`, 이어서 `BROWSER_OPERATOR_APPROVAL.sql`을 SQL Editor에서 DB 운영자로 실행합니다. 기존 DB에서는 후자만 실행합니다. 서버 전용 설정은 기존 `SUPABASE_URL`과 `SUPABASE_SECRET_KEY`이며 브라우저에 넣지 않습니다.

## 요청·승인·취소

1. 자료실에서 로그인 → **기기 승인 요청**. 화면에 승인 대기와 요청 번호가 표시됩니다. 이때 자료는 표시되지 않습니다.
2. 운영자가 요청 번호를 요청자에게 확인하고, SQL Editor에서 다음 조회의 UUID를 화면의 요청 번호로 바꿉니다. 이 번호는 쿠키 원문이 아니며, 번호만 알아도 승인 권한은 없습니다. 사용자 ID·요청 시각·만료·대기 상태를 함께 확인합니다. 다른 사람의 요청을 임의로 승인하지 않습니다.

```sql
select request_id, user_id, status, requested_at, expires_at
from public.learning_browser_registrations
where request_id = '화면의-요청-UUID'::uuid;
```

3. 확인한 한 건만 승인합니다. 이 함수는 DB 운영자만 실행할 수 있습니다. 승인 변경과 감사 행 추가는 같은 트랜잭션이며, 감사 기록 실패 시 승인도 실패합니다.

```sql
select * from public.review_learning_browser_registration('화면의-요청-UUID'::uuid, true);
```

4. 화면에서 **승인 결과 확인**을 누릅니다. 서버가 운영자 승인 기록·사용자·브라우저·만료를 다시 확인하고 DB의 운영자 승인 상태가 유효한 경우 본인 메모 목록과 기존 편집 화면을 엽니다.
5. 승인 취소 또는 대기 요청 거절은 같은 UUID로 다음을 실행합니다. 다음 자료 요청부터 거부되며 화면의 보호 자료를 지웁니다.

```sql
select * from public.review_learning_browser_registration('화면의-요청-UUID'::uuid, false);
```

## 확인

학습 DB 확인용 `test/browser-registration-db.sql`은 시험 계정의 가상 요청으로 권한·승인·취소·감사·5건 제한을 검사한 뒤 롤백합니다. 실제 사용자 기기 승인이나 배포 브라우저 시험을 대신하지 않습니다.

`npm run test:stage11 && npm run decider:test && npm run build -- --local`

승인 전 상태 조회·요청 버튼을 반복해도 대기 상태여야 합니다. 메모 API 직접 요청은 미로그인 401, 미승인 403 `DEVICE_NOT_APPROVED`이며 자료가 없어야 합니다. 승인 후 본인 메모 CRUD는 유지하고 상대 소유 메모는 기존 규칙으로 거부합니다. 다른 브라우저·다른 사용자·만료·취소는 허용하지 않습니다. DB 장애는 자료 없는 503이며 자동 승인으로 우회하지 않습니다. 한 사용자당 유효한 대기 요청은 DB 잠금으로 최대 5건입니다. 앱 서버는 status를 INSERT·UPDATE하거나 운영자 승인 함수를 호출할 수 없습니다.

브라우저 쿠키를 지우면 새 브라우저로 취급합니다. 로그인 토큰은 실행 메모리에만 있고 새로고침하면 다시 로그인합니다. 등록 기록은 로그인과 별개이므로 같은 사용자로 다시 로그인해도 유지됩니다. 브라우저 식별 쿠키가 탈취되면 같은 사용자 인증과 함께 악용될 수 있는 한계가 있습니다. 기기 키나 Supabase JWT·갱신 토큰은 브라우저 저장소에 넣지 않습니다.
