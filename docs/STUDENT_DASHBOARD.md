# 케셰브 내 PC 실측 화면

## 제공 기능과 학생 작성 부분
| 구분 | 경로 | 역할 |
|---|---|---|
| 제공 | on-client/src/pc-status.mjs | 일반 권한으로 CPU·메모리·프로젝트 파일시스템·방화벽 등을 읽음 |
| 제공 | on-client/public/app.js | 학생 api.get('/api/pc/status') 제공 |
| 제공 | on-client/public/pc-status-view.mjs | 기존 내 PC 상태 카드. 그대로 유지 |
| 학생 | on-client/student/extension.mjs | renderStatus 앞에 네 카드와 측정 설명 추가. 앞 단계 표시 유지 |

수집기를 중복 구현하지 않습니다. 학생 버튼은 같은 제공 API로 별도의 새 측정을 요청하므로 기존 제공 카드와 측정 시각·수치가 다를 수 있습니다.
포장 없이 프로젝트 폴더에서 실행하며 포장 명령을 사용하지 않습니다.

## 값과 시각
- CPU: %, 제공된 sampleMs는 ms. 짧은 표본 구간이므로 작업 관리자와 항상 같지 않습니다.
- 메모리: 사용량/전체 GiB 및 사용률 %. PC 전체이며 앱 전용 사용량이 아닙니다.
- 디스크: 남은 공간/전체 GiB. 프로젝트가 있는 파일시스템이며 모든 드라이브 합계가 아닙니다.
- 방화벽: Domain/Private/Public 켜짐·꺼짐. 수치 단위 해당 없음.
- GiB = 1024³ 바이트.
- 각 카드의 측정 묶음 시각은 measuredAt 원문 및 한국 시각입니다. 전체 조회 완료 시각이며 항목별 동시 측정을 뜻하지 않습니다.
- 측정하지 않음·통신 실패·권한 부족·미지원·시간 초과·잘못된 응답은 확인 불가와 이유를 표시합니다. 이전 수치를 현재 값으로 남기거나 예시 값으로 대체하지 않습니다.
- 자동 조회·AI 요청·외부 전송·OS 변경·관리자 권한 요청을 추가하지 않았습니다.
- 선택한 설명 기능은 ‘측정 결과 읽는 법’입니다. 추이 그래프와 과거 이력 저장은 이번 범위에 포함하지 않습니다.

## 실행 및 확인
기존 실행 중인 앱을 해당 터미널에서 Ctrl+C로 종료한 뒤 실행합니다.
```powershell
cd "C:\Users\sum\Desktop\방어전\choi-bujang-secret-vault\on-client"
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```
브라우저: http://127.0.0.1:5189

1. 보호 현황의 학생 상태 영역에서 ‘케셰브 · 내 PC 실측’을 찾습니다.
2. ‘PC 상태 새로 측정’을 누릅니다. CPU %, 메모리·디스크 GiB와 각 카드의 측정 시각을 확인합니다.
3. 읽지 못한 항목은 확인 불가와 이유가 나오는지 확인합니다. 예시 수치를 실제 결과로 해석하지 않습니다.
4. 다시 눌러 새 시각으로 바뀌는지 확인합니다. 측정 중에는 이전 수치를 현재 값으로 표시하지 않습니다.
5. 기존 로그인·업무 앱·보안 기록과 도움정보 복사가 유지되는지 확인합니다.
6. Ctrl+C로 종료하고 같은 명령으로 재실행합니다. 학생 PC 실측은 다시 버튼을 눌러 확인합니다.

## 검증 구분
소스 검토·문법 검사·모의 DOM 점검은 개발 확인입니다. 수민 PC에서의 실제 수치와 화면 확인을 대신하지 않습니다.
실측 화면·기존 기능 회귀 확인은 이 변경을 PC에 반영한 뒤 사용자가 확인해야 합니다.
이 문서는 앞서 제출한 22단계 실행 증거를 변경하거나 새 버전 실행 성공을 주장하지 않습니다.


## 네트워크·방화벽·Windows 기록 확장
학생 상태 영역의 기존 카드 네 개를 보존하고 아래에 네트워크·Windows 기록을 추가합니다.
수집과 서버 API는 제공 기능이며, 학생 코드는 표시·실패 이유·범위 설명만 추가합니다.
- 네트워크는 일반 권한 Node API가 읽은 비내부 인터페이스 수와 IPv4 주소 수(개)입니다. 인터넷 연결 검사나 IP·DNS 상세 구성을 제공하지 않습니다.
- 방화벽은 Domain/Private/Public 프로필 켜짐·꺼짐만 읽습니다. 규칙을 수정하거나 관리자 권한을 요구하지 않습니다.
- Windows 기록은 최근 약 24시간의 System·Application 경고·오류 합산(건)입니다. 제공 API는 최신 최대 5,000건을 집계하며 truncated일 때 생략을 명시합니다. 로그별 건수·원문은 전달되지 않습니다.
- **이 건수는 침해나 공격 탐지 결과가 아닙니다.**
- 각 PC 항목에 공통 측정 묶음 시각을 붙입니다. 기록 조회 시작은 since, 끝은 measuredAt입니다. 권한 거부·미지원·실패·잘못된 응답은 0건으로 바꾸지 않습니다.
- SDP는 renderStatus의 devices·sessions 입력으로 별도 표시합니다. 두 입력 모두 error/disconnected/ENGINE_NOT_CONNECTED일 때만 SDP 미연결, 둘 다 ok/connected일 때 연결됨입니다. demo·조회 중·통신 실패·인증 오류·혼합 상태는 확인 불가와 이유를 표시합니다. PC API의 성공·mode를 SDP 연결 근거로 쓰지 않습니다.
- 학생 상태 입력에는 SDP 점검 시각이 없으므로 PC 측정 시각을 SDP 점검 시각처럼 붙이지 않습니다. 표시된 상태는 마지막으로 전달받은 입력 기준이며 실시간 연결 보증이 아닙니다.
- 예시 데이터·설정 변경·공격 시험·자동 요청·포장 명령은 추가하지 않습니다.

추가 확인: PC 상태 새로 측정 → 네트워크 개수·Windows 건수·측정 시각 확인 → SDP 별도 문구 확인.
SDP 재확인은 제공 화면의 다시 불러오기를 직접 누릅니다. PC 측정 버튼은 SDP 재연결을 수행하지 않습니다.
실제 PC에서 이번 확장의 화면·권한 실패·Windows 집계는 아직 미확인입니다.
